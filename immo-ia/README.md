# ImmoIA

Recherche immobilière d'investissement en France : annonces analysées (prix vs marché, rendement net, cash-flow, facilité de négociation, offre conseillée).

    node immo-ia/server.js   # puis http://localhost:3000

Aucune dépendance. Les annonces et prix de marché sont des données de démonstration (`data.js`).
